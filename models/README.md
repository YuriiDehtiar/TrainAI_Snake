# Збережені моделі

| Папка | Ітерація | Перемоги на тих самих 200 нових іграх | Середнє яблук |
|---|---:|---:|---:|
| `iteration_000950` | 950 | 154 / 200 (77%) | 55,365 |
| `iteration_002000` | 2000 | 178 / 200 (89%) | 58,26 |

У кожній папці `policy.pt` містить лише тензори ваг Actor і Critic на CPU. `model.json` описує архітектуру, правила середовища, результат тесту та SHA-256 ваг. Завантажувач перевіряє контрольну суму й читає ваги через `torch.load(..., weights_only=True)`.

Це переносні моделі для гри та оцінювання. Вони не містять стану оптимізатора, генераторів випадкових чисел, системних журналів або локальних шляхів. `snake-train --weights models/iteration_002000 --run-name warm_start` починає нове навчання з цих ваг і новим Adam. Точне продовження Adam та стану ігор потребує повного локального checkpoint і параметра `--resume`.

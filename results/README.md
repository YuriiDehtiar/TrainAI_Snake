# Результати останнього навчання

`latest/` містить одну безперервну історію від випадкових ваг до ітерації 2000. Продовження після зупинок належать цьому самому навчанню.

| Файл | Вміст |
|---|---|
| `config.json` | Правила середовища й параметри PPO |
| `metrics.jsonl` | Показники кожної з 2000 ітерацій |
| `episodes.csv` | 452 388 завершених навчальних ігор |
| `summary.json` | Загальна статистика, етапи навчання й підсумки тестів |
| `evaluation_000950.json` | 200 нових тестових ігор моделі 950 |
| `evaluation_002000.json` | Ті самі 200 ігор моделі 2000 |
| `loss_replay.json` | Повторення 22 поразок фінальної моделі й перевірка трьох останніх дій |

В `metrics.jsonl` показники `apples_mean`, `win_rate` і мінімум/максимум стосуються останніх 100 завершених ігор. Поля із суфіксом `_total` охоплюють усю збережену історію. Лічильник `environment_steps` рахує нові переходи гри. Повторне використання ходів у 10 епохах не збільшує цей лічильник.

Публічний експорт містить лише параметри навчання та дані гри. Температури, споживання, назви й ідентифікатори пристроїв, швидкість обладнання, системні події, ідентифікатори процесів та абсолютні шляхи до нього не входять. Сирі локальні папки `runs`, `sessions` і `diagnostics` ігноруються Git.

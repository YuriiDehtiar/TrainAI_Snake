# Навчання та продовження

## Параметри останнього навчання

| Параметр | Значення |
|---|---:|
| Паралельні середовища | 1024 |
| Ходів із кожного середовища | 64 |
| Нових переходів за ітерацію | 65 536 |
| Мінібатч | 16 384 |
| Епох на одному наборі | 10 |
| Оптимізатор | Adam |
| Learning rate | 0,0003 |
| Gamma | 0,99 |
| GAE lambda | 0,95 |
| Коефіцієнт ентропії | 0,01 |
| PPO clip | 0,2 |
| Gradient clip | 0,5 |
| Value clip | 10 |
| Seed | 42 |

Протягом збору 64 ходів ваги мережі фіксовані. Це послідовні нові ходи, а не випадкова вибірка з усієї партії. Якщо гра завершується, середовище починає нову й продовжує збір. Довгі партії переходять до наступного набору.

GAE оцінює користь дії відносно очікувань Critic з урахуванням наступних винагород. PPO використовує цю оцінку для Actor, а Critic навчається точніше передбачати винагороду. Один набір ділиться на 4 мінібатчі. У 10 епохах Adam виконує 40 оновлень, після чого мережа збирає нові ходи.

## Винагороди

Яблуко дає +1, звичайний хід −0,01, зіткнення або голодування −1. Перемога додає +5 до винагороди останнього яблука. Ліміт без яблука становить 256 ходів, загальний ліміт партії 6400.

У KL використано обчислення через логарифми ймовірностей. Воно усуває числову нескінченність для дуже малих імовірностей. Це не змінює архітектуру, винагороди або доступні дії.

## Запуск з нуля

```powershell
snake-train --run-name experiment_01 --settings-from configs/training.json --iterations 2000
snake-dashboard --run-dir runs/experiment_01
```

Команди запускаються окремо. У Windows `.\scripts\start-live.ps1 -RunName experiment_01 -Iterations 2000` робить це одним запуском. Для іншого розміру збору є параметри `--num-envs`, `--horizon`, `--minibatch-size` та `--epochs`. Їхня зміна впливає і на траєкторію навчання.

## Два способи використати попередні ваги

**Повне продовження локального навчання:**

```powershell
snake-train --run-name continuation_01 --resume runs/experiment_01/checkpoints/iteration_002000 --iterations 2500
```

`--iterations` задає кінцевий номер: тут додаються ітерації 2001–2500. Відновлюються ваги, Adam, ігри та генератори випадковості. Кількість паралельних середовищ має відповідати збереженому стану. Історія до checkpoint копіюється до нового запуску, вихідний запуск зберігається.

**Нове навчання з публічних ваг:**

```powershell
snake-train --run-name warm_start_01 --weights models/iteration_002000 --iterations 500
```

Цей варіант переносить тільки Actor і Critic. Adam, ігри й лічильник ітерацій починаються заново. Це новий дослід, а не точне продовження попереднього оптимізатора. `--weights` та `--resume` не можна поєднувати.

## Живе вікно й збереження

Навчання записує легкі ваги після кожної ітерації. Показова змійка бере найновіші готові ваги перед новою грою. Якщо нових немає, вона повторно використовує поточні. Повний checkpoint записується кожні 20 ітерацій і при завершенні.

Кнопка зупинки створює файл `STOP`: тренер завершує поточну ітерацію й зберігається. Закриття вікна з графіками не зупиняє тренер. `.\scripts\start-live.ps1 -DashboardOnly` відкриває вікно повторно.

Нові `runs/` і `sessions/` залишаються локальними. Перед публікацією експортуйте лише дані гри та перевірте список файлів через `python tools/check_public_files.py`.
